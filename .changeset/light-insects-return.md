Mutant.IgnoreRuleId gains constant-collection-size: a comparison of an array, tuple or string length with zero that the TypeScript checker proves always true or always false (such as xs.length >= 0) is Ignored under this rule when a kept mutant at the same site already replaces the comparison with that constant. Code that switches exhaustively over IgnoreRuleId must handle the new id.
