The run stream moves to schema version `9.0`, so a stream reader pinned to `8.0` must accept `9.0`. An Ignored mutant may carry the reason `constant-collection-size` when the TypeScript checker is configured. Under the default `mutator.mutantSetPolicy`, a replacement is no longer Ignored as `equivalent-to-original` or `duplicate-at-site` merely because stripping its parentheses would make it match, so mutation scores can change.
