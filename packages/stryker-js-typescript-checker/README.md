# @systemfsoftware/stryker-js-typescript-checker

TypeScript checker plugin for Stryker — TS7 native

## Install

```sh
pnpm add @systemfsoftware/stryker-js-typescript-checker
```

## Entry points

- `@systemfsoftware/stryker-js-typescript-checker`

## Use

Name the plugin in your Stryker configuration:

```json
{
  "plugins": ["@systemfsoftware/stryker-js-typescript-checker"]
}
```
